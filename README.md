# 🌐 Enterprise Network Lab

An enterprise network implementation using Cisco routers and switches,
with network segmentation, VLANs, inter-VLAN routing, DHCP, SSH,
RADIUS, and ACLs.

---

## 📌 Project Overview

This project demonstrates the design and implementation of an enterprise
network environment using Cisco networking technologies.

The topology includes multiple network segments for users, servers,
wireless clients, and infrastructure devices.

The project focuses on network segmentation, secure device management,
IP addressing, routing, and access control.

## 🔀 VLANs

VLANs are used to logically separate different groups of devices
within the enterprise network.

This improves:

- Network segmentation
- Security
- Traffic management
- Broadcast domain isolation

---

## 🌐 Inter-VLAN Routing

Inter-VLAN routing is implemented to allow communication between
different VLANs while maintaining logical network segmentation.

---

## 📡 DHCP

DHCP is used to provide network configuration dynamically to
client devices.

The configuration includes:

- IP Address
- Subnet Mask
- Default Gateway
- DNS information

---

## 🔐 Secure Device Management

### SSH

SSH is configured for secure remote management of network devices.

Instead of using insecure remote management methods, SSH provides
encrypted administrative access.

### RADIUS

RADIUS is used as an authentication mechanism for centralized
network device access.

### Local User Authentication

Local user accounts are configured as an additional authentication
method for device administration.

---

## 🛡️ Access Control Lists

ACLs are used to control and filter network traffic according to
defined access requirements.

They help restrict unauthorized communication between network
segments.

## 🎯 Project Objectives

The main objectives of this project are:

1. Build an enterprise-style network topology.
2. Implement network segmentation using VLANs.
3. Enable communication between VLANs.
4. Configure dynamic IP addressing using DHCP.
5. Implement secure remote management using SSH.
6. Configure authentication using RADIUS and local users.
7. Apply ACLs to control network traffic.
8. Practice network troubleshooting.
